# Тренировки — личный дневник

**Текущая версия: 2.0.1 (дизайн Halo).** Офлайн PWA для ведения силовых тренировок. Нет аккаунта, бэкенда, CDN, рекламы, аналитики или удалённой синхронизации. Тренировки, замеры и настройки хранятся локально в браузере пользователя.

## Возможности

- Пять основных вкладок в стиле iOS: Главная, Тренировка, История, Прогресс и «Ещё». В «Ещё» собраны Упражнения, Параметры тела и Профиль.
- Быстрая запись веса и повторов, автоподстановка предыдущих значений, разминка и отдых.
- **Постоянная live-панель внутри приложения:** текущее упражнение, время тренировки и обратный отсчёт отдыха; панель остаётся видимой при переходах между вкладками.
- Звуковой сигнал окончания отдыха с отдельным переключателем в настройках.
- Таймер отдыха сверяется с абсолютным временем и пересчитывается при возвращении приложения из фона.
- Библиотека упражнений, блоки и программы с расписанием; полный список упражнений в программе можно раскрыть, а тренировочный день — отредактировать.
- История, календарь, редактирование, SVG-графики, рабочий объём и личные рекорды. В прогресс попадают только завершённые рабочие подходы.
- Замеры тела, цели, уровни, серии и 32 сворачиваемых достижения.
- **Дизайн Halo (v2.0):** чёрное стекло, тонкие линии, моно-подписи, красный акцент и сегментные шкалы. На компьютере слева стеклянная боковая панель, которая сворачивается в узкую колонку иконок с подсказками (клавиша `[`). На телефоне плавающая стеклянная панель вкладок.
- Поиск и команды по `Ctrl K` / `⌘K` (кнопка в панели или в шапке): переход по разделам, быстрые действия, поиск упражнений. Горячие клавиши: `1–7` разделы, `N` быстрое действие.
- Светлая, тёмная и системная темы, мягкое «гало» сверху и лёгкие частицы на фоне (отключаются при «уменьшении движения»), анимированные переходы, жест закрытия модальных листов.
- JSON-резервная копия, XLSX и отдельный безопасный импорт программы от ИИ-тренера.

## Публикация на GitHub Pages

1. Откройте **Settings → Pages**.
2. В **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку `main` и папку `/ (root)`, сохраните.
4. Откройте адрес GitHub Pages по HTTPS и дождитесь первой загрузки. Service worker закэширует ресурсы.
5. После успешного первого запуска дневник открывается офлайн.

Все пути относительные — поддерживается публикация в подкаталоге репозитория.

## Установка на телефон

- **iPhone:** Safari → «Поделиться» → «На экран Домой» → «Добавить».
- **Android:** Chrome → меню → «Установить приложение» / «Добавить на главный экран».

## Работа с ИИ-тренером

Обычный цикл: в дневнике записываются фактические подходы → в Профиле скачивается JSON-копия → пользователь вручную передаёт её ИИ-тренеру для анализа → тренер возвращает отдельный `coach-plan.json` → пользователь открывает **Профиль → Программа от ИИ-тренера**. Рядом с загрузкой есть кнопка **Промт для ИИ**: она показывает готовую инструкцию по формату файла и позволяет скопировать её одним нажатием.

Этот отдельный импорт имеет только добавочный режим. Он создаёт новые упражнения, блоки и планы, сопоставляет упражнения по названию/оборудованию, пропускает уже загруженные ID. Он **не заменяет** тренировки, замеры, цели и настройки. Повторная загрузка той же программы не создаёт дубликат. Новая редакция программы должна иметь новый ID. Импорт программы создаёт шаблон, но не записывает вымышленные завершённые тренировки.

Полная схема, поля и системная инструкция для ИИ описаны в [COACH_AI_MANUAL.md](./COACH_AI_MANUAL.md). Обезличенный пример лежит в [coach-plan-template.json](./coach-plan-template.json).

## Резервное копирование

В **Профиль → Данные и резервные копии** доступны:
- JSON — полная копия состояния для восстановления или передачи тренеру;
- XLSX — отдельные листы: тренировки, подходы, упражнения, блоки, программы, замеры, цели;
- импорт JSON/XLSX с предпросмотром и режимом объединения/замены.

Для обычного восстановления используйте JSON-копию. Импорт программы тренера — отдельный и только добавочный механизм.

## Ограничения и приватность

- Live-панель — это элемент интерфейса внутри PWA. Статическая веб-страница не может создавать нативную iOS Live Activity на Dynamic Island/экране блокировки или гарантировать системное уведомление при закрытом приложении.
- Когда браузер/ОС приостанавливает страницу в фоне, секундный таймер может не обновляться до возвращения. После возвращения приложение сверяет абсолютное время отдыха и обновляет состояние; звуковой сигнал зависит от поддержки Web Audio и разрешения браузера на воспроизведение.
- Данные привязаны к браузеру и origin на устройстве. Локальный `file://` и GitHub Pages имеют разные хранилища.
- Очистка данных сайта, удаление профиля браузера или потеря устройства может удалить записи. Храните JSON-копию отдельно.
- Браузер может отказать в постоянном хранилище, несмотря на запрос `navigator.storage.persist()`.
- `standalone.html` не устанавливается как PWA и не регистрирует service worker.
- Приложение не отправляет пользовательские данные в сеть. При экспорте и последующей передаче JSON ИИ-сервису пользователь сам делится содержимым файла; в нём могут быть чувствительные сведения о замерах и тренировках.

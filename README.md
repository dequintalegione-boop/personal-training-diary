# Тренировки — личный дневник

Офлайн PWA для записи силовых тренировок. Стек: HTML, CSS и чистый JavaScript, без сборщика, CDN, бэкенда, аналитики и внешних библиотек. Пользовательские данные хранятся локально в IndexedDB (с резервом localStorage).

## Запуск и публикация

1. В GitHub откройте **Settings → Pages**.
2. В **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и сохраните.
3. Откройте опубликованный HTTPS-адрес. При первом открытии дождитесь загрузки ресурсов и регистрации service worker — после этого приложение работает офлайн.

Пути относительные, поэтому поддерживается GitHub Pages в подкаталоге репозитория.

## Установка

- **iOS:** Safari → «Поделиться» → «На экран Домой».
- **Android:** Chrome → меню → «Установить приложение» / «Добавить на главный экран».

## Данные и резервные копии

В профиле доступны экспорт полной резервной копии JSON и экспорт таблицы XLSX (тренировки, подходы, упражнения, блоки, программы, замеры, цели). Импорт поддерживает предпросмотр, объединение и замену данных. Рекомендуется регулярно сохранять JSON отдельно от устройства.

## Ограничения

- Данные принадлежат конкретному браузеру и адресу сайта. GitHub Pages не хранит пользовательские записи.
- При очистке данных сайта или потере устройства записи могут исчезнуть; восстанавливайте их из JSON-копии.
- Браузер может отказать в постоянном хранилище, несмотря на запрос `navigator.storage.persist()`.
- `standalone.html` для локального запуска не устанавливается как PWA и не регистрирует service worker.
- Импорт XLSX рассчитан на обычные книги Excel; для наиболее полного восстановления используйте JSON.

Приложение не отправляет тренировки и замеры в сеть. При загрузке/обновлении запрашиваются только статические файлы самого сайта.

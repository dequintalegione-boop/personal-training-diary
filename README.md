# Тренировки — личный дневник

Офлайн PWA для ведения силовых тренировок. Нет аккаунта, бэкенда, CDN, рекламы, аналитики или удалённой синхронизации. Тренировки, замеры и настройки хранятся локально в браузере пользователя.

## Что есть в приложении

- Семь разделов: Главная, Тренировка, История, Упражнения, Прогресс, Тело и Профиль.
- Запись фактических весов/повторов, автоподстановка с предыдущего выполнения, разминка, отдых и таймер.
- Библиотека упражнений, блоки и программы с расписанием.
- История, редактирование, календарь, SVG-графики, рабочий объём и личные рекорды.
- Замеры тела, цели, уровни, серии и 32 достижения.
- Светлая/тёмная/системная темы.
- JSON резервная копия, XLSX и отдельный безопасный импорт программы от ИИ-тренера.

## Структура

```text

```

## Публикация на GitHub Pages

1. Откройте **Settings → Pages**.
2. В **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку `main` и папку `/ (root)`, сохраните.
4. Откройте адрес GitHub Pages по HTTPS и дождитесь первой загрузки. Service worker закэширует ресурсы.
5. После успешного первого запуска дневник открывается офлайн.

Все пути относительные — поддерживается публикация в подкаталоге репозитория.

## Установка на телефон

- **iPhone:** Safari → «Поделиться» → «На экран Домой» → «Добавить».
- **Android:** Chrome → меню → «Установить приложение» / «Добавить на главный экран».

## Работа с ИИ-тренером

Обычный цикл: в дневнике записываются фактические подходы → в Профиле скачивается JSON-копия → пользователь вручную передаёт её ИИ-тренеру для анализа → тренер возвращает отдельный `coach-plan.json` → пользователь открывает **Профиль → Программа от ИИ-тренера → Загрузить программу тренера**.

Этот отдельный импорт имеет только добавочный режим. Он создаёт новые упражнения, блоки и планы, сопоставляет упражнения по названию/оборудованию, пропускает уже загруженные ID. Он **не заменяет** тренировки, замеры, цели и настройки. Повторная загрузка той же программы не создаёт дубликат. Новая редакция программы должна иметь новый ID. Импорт программы создаёт шаблон, но не записывает вымышленные завершённые тренировки.

Полная схема, поля и системная инструкция для ИИ описаны в [COACH_AI_MANUAL.md](./COACH_AI_MANUAL.md). Обезличенный пример лежит в [coach-plan-template.json](./coach-plan-template.json).

## Резервное копирование

В **Профиль → Данные и резервные копии** доступны:
- JSON — полная копия состояния для восстановления или передачи тренеру;
- XLSX — отдельные листы: тренировки, подходы, упражнения, блоки, программы, замеры, цели;
- импорт JSON/XLSX с предпросмотром и режимом объединения/замены.

Для обычного восстановления используйте JSON-копию. Импорт программы тренера — отдельный и только добавочный механизм.

## Ограничения и приватность

- Данные привязаны к браузеру и origin на устройстве. Локальный `file://` и GitHub Pages имеют разные хранилища.
- Очистка данных сайта, удаление профиля браузера или потеря устройства может удалить записи. Храните JSON-копию отдельно.
- Браузер может отказать в постоянном хранилище, несмотря на запрос `navigator.storage.persist()`.
- `standalone.html` не устанавливается как PWA и не регистрирует service worker.
- Приложение не отправляет пользовательские данные в сеть. При экспорте и последующей передаче JSON ИИ-сервису пользователь сам делится содержимым файла; в нём могут быть чувствительные сведения о замерах и тренировках.

# Тренировки — личный дневник

Офлайн PWA для записи силовых тренировок. Стек: HTML, CSS и чистый JavaScript, без сборщика, CDN, бэкенда, аналитики и внешних библиотек. Пользовательские данные хранятся локально в IndexedDB (с резервом localStorage).

## Структура проекта

- `index.html`, `manifest.webmanifest`, `sw.js` — PWA-точка входа, установка, cache-first офлайн-кэш.
- `css/styles.css` — адаптивный интерфейс, светлая и тёмная темы.
- `js/db.js` — IndexedDB, localStorage fallback и запрос `navigator.storage.persist()`.
- `js/utils.js`, `js/charts.js` — даты, форматирование, SVG-иконки, графики и карта активности.
- `js/xlsx.js`, `js/backup.js` — XLSX и JSON экспорт/импорт, предпросмотр и валидация.
- `js/app-loader.js` загружает исполняемый runtime из `js/app-boot-00.txt` … `js/app-boot-05.txt`. Это части одного gzip-пакета в Base64; загрузчик собирает их и распаковывает встроенным `DecompressionStream`. Внешние сервисы не используются. Читаемый исходник приложения `js/app.js` находится в ZIP-пакете проекта.

## Публикация на GitHub Pages

1. В GitHub откройте **Settings → Pages**.
2. В **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку `main` и папку `/ (root)`, сохраните.
4. Откройте адрес GitHub Pages. Пути относительные, поэтому проект работает и в подкаталоге репозитория.
5. Для первого запуска откройте сайт онлайн, дождитесь регистрации service worker. После этого приложение сможет запускаться офлайн.

## Установка на телефон

- **iOS:** Safari → «Поделиться» → «На экран Домой» → «Добавить».
- **Android:** Chrome → меню → «Установить приложение» / «Добавить на главный экран».

## Резервное копирование

В разделе **Профиль → Данные и резервные копии** доступны:
- JSON — полная резервная копия состояния для восстановления;
- XLSX — отдельные листы: тренировки, подходы, упражнения, блоки, программы, замеры и цели;
- импорт JSON/XLSX с предпросмотром, объединением или заменой.

Храните JSON-копию отдельно от телефона/браузера и обновляйте её регулярно.

## Ограничения и приватность

- Данные привязаны к браузеру и origin на устройстве. GitHub Pages не хранит пользовательские записи.
- Очистка данных сайта, профиля браузера или потеря устройства может удалить записи. Для восстановления нужен файл резервной копии.
- `navigator.storage.persist()` запрашивается, но браузер сам решает, предоставлять ли постоянное хранилище.
- `standalone.html` — локальная версия без установки PWA и service worker.
- XLSX импорт рассчитан на обычные книги Excel; для наиболее полного восстановления используйте JSON.
- Реализован базовый уровень целей, рекордов, аналитики и программ. Продвинутая периодизация, полный набор прогнозов и некоторые расширенные аналитические отчёты из большого ТЗ требуют следующих итераций.
- Приложение не отправляет тренировки и замеры в сеть. Первичная загрузка и обновления затрагивают только статические файлы самого сайта. Нет входа, PIN, аналитики, push, звука, вибрации, рекламы или платных функций.

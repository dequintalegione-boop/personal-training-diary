# Статистика посещений сайта

В проект встроена необязательная интеграция с [GoatCounter](https://www.goatcounter.com/) — бесплатным сервисом веб-аналитики для обычных и небольших сайтов.

## Как включить

1. Создай аккаунт на [goatcounter.com/signup](https://www.goatcounter.com/signup). Поле **Account name** станет адресом панели, например `my-training-diary.goatcounter.com`.
2. Открой файл `js/analytics-config.js` в репозитории.
3. Замени пустое значение на имя аккаунта — только часть до `.goatcounter.com`:

   ```js
   window.PTD_GOATCOUNTER_SITE = 'my-training-diary';
   ```

4. Сохрани изменение в ветке `main` и дождись публикации GitHub Pages.
5. Открой панель по адресу `https://my-training-diary.goatcounter.com` (подставь своё имя аккаунта).

После публикации статистика начнёт поступать при посещениях сайта. Первые данные могут появиться не мгновенно.

## Что будет видно

- посещения и уникальные визиты;
- просмотры отдельных разделов приложения: главная, тренировка, история, прогресс, упражнения, параметры тела и профиль;
- сайты-источники переходов;
- статистика по браузерам, размерам экранов и примерному местоположению посетителей.

## Что сервис не покажет

GoatCounter не раскрывает реальные имена посетителей и не позволяет установить, какой конкретно человек открыл страницу. Он не использует cookies и постоянные личные идентификаторы; статистика предназначена для анализа аудитории, а не для слежки за отдельными людьми. Подробности — в [описании возможностей](https://www.goatcounter.com/) и [условиях сервиса](https://www.goatcounter.com/help/terms).

## Приватность и офлайн-режим

- В аналитику отправляются адрес раздела приложения и обычные метаданные посещения. Код не читает IndexedDB, localStorage, тренировки, упражнения, замеры, цели или резервные копии.
- Аналитика включается только после заполнения `js/analytics-config.js` и работает на опубликованной HTTPS-версии.
- Локальный запуск через `file://`, localhost и отдельный `standalone.html` не отслеживаются.
- Если сервис недоступен или устройство офлайн, приложение продолжает работать; статистика за это время не отправится.
- Конфигурационный файл намеренно не сохраняется в кэше Service Worker, поэтому изменение кода сайта применяется после публикации без ручной очистки кэша. В офлайне для него используется пустая конфигурация, и трекер не запускается.

Чтобы полностью отключить сбор статистики, верни пустую строку:

```js
window.PTD_GOATCOUNTER_SITE = '';
```

Код сайта — не пароль и не секрет. Не добавляй в репозиторий пароль от GoatCounter и не передавай его другим людям.
